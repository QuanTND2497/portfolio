# Portfolio

A responsive, dependency-free portfolio starter. Open `index.html` in a browser, or run `python3 -m http.server 8000` and visit `http://localhost:8000`.

## Make it yours

- Update personal details and contact information in `index.html`.
- The two project descriptions are based on the information provided; the visual mockups are illustrative and do not show the actual products.
- Update the title and description in the document head.
- Adjust colors and layout in `styles.css`. No build step is required.

## Design research

The layout combines the typography-led, high-contrast approach described in [Figma's portfolio examples](https://www.figma.com/resource-library/portfolio-website-examples/) with the clear introduction, selected work, and contact structure in [We.Inc's developer portfolio examples](https://we.inc/guides/developer-portfolio-examples). The warm editorial palette draws inspiration from [Tarik Karahodžić's portfolio redesign](https://www.tarikkarahodzic.dev/projects/personal-site).
